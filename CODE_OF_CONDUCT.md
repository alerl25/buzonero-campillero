# Código de conducta

Este proyecto sigue el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

**En corto:**
- Trata a todo el mundo con respeto, sin importar su experiencia, origen o identidad.
- Critica ideas, no personas.
- Acoge a quien empieza.
- No se toleran el acoso, los insultos ni compartir datos privados de otras personas, y eso incluye sus correos.

Si ves algo que no encaja, escribe a quien mantiene el proyecto con el [aviso privado de GitHub](../../security/advisories/new) o abriendo un issue. Se tratará con discreción.
